# 🎓 Nous — ИИ-помощник для подготовки к ЕГЭ

**Nous** (греч. «ум, разум») — локальное десктопное приложение для Windows. Помогает готовиться к ЕГЭ: держит план и расписание, хранит твои материалы, гоняет по банку заданий и ведёт прогресс с уровнями и достижениями.

**Приложение самодостаточно без ИИ.** Задания оно собирает само и по числу не ограничено, план собирается по структуре экзамена, текст из твоих файлов вынимается на твоём же компьютере, короткие ответы сверяются с эталоном — всё это работает офлайн и без ключей. ИИ подключается сверху и делает то, чего офлайн не сделать: проверяет развёрнутые ответы по критериям, готовит теорию к занятию, разбирает неделю. Ключ можно не заводить вовсе — подойдёт локальная модель (Ollama, LM Studio).

## 💡 Как это работает

План можно получить тремя способами — от «прямо сейчас, без всего» до «с сильным ИИ»:

1. **Без ИИ и без интернета.** Кнопка «Собрать план по структуре ЕГЭ»: каждое задание КИМ закрывается теорией, практикой и повторением. Если в тренажёре уже копится статистика, по слабым номерам добавляется лишний подход.
2. **Своим ИИ прямо в приложении.** Работает на твоём ключе или на локальной модели.
3. **Чужим сильным ИИ.** Приложение готовит подробный промт → копируешь в ChatGPT/DeepSeek → вставляешь ответ обратно, и он раскладывается по календарю. Сюда же можно вставить и свой готовый план в любом виде.

Дальше план живёт в календаре: занятия переносятся мышью, добавляются свои дела, отмечаются выходные и каникулы.

## ✨ Что умеет

**Работает всегда — без ключей и без интернета**

- 🗓️ **Расписание под себя** — занятие переносится на другой день перетаскиванием, дни недели и нагрузка настраиваются по каждому предмету, выходные и каникулы план обходит сам. Просроченное раскладывается по ближайшим дням одной кнопкой.
- 📌 **Свои дела в календаре** — репетитор, пробник, тренировка: всё рядом с занятиями плана.
- 📚 **Материалы** — свои учебники, варианты, конспекты и таблицы: PDF, DOCX, EPUB, FB2, TXT, MD, CSV, JSON, картинки. Текст вынимается на твоём компьютере (включая кириллицу в windows-1251), поиск идёт **по содержимому файлов**, материал привязывается к занятию.
- 🎯 **Тренажёр и свой банк заданий** — задания берутся из твоего файла (колонки размечаешь сам — подойдёт любой формат), из загруженного материала или вводятся руками. Короткий ответ сверяется с эталоном на месте, в подход первыми идут те, где ошибался.
- 🧭 **Статистика по темам, а не по номерам** — «сыплюсь на двенадцатом» не говорит ничего, «не понимаю начала анализа» говорит всё: это девятое, двенадцатое и семнадцатое задания сразу, и чинить их надо вместе. Разделы взяты из кодификатора ФИПИ.
- 💰 **Цена балла** — что подтянуть первым, посчитано арифметикой: вес номера на экзамене умножить на долю, которую ты в нём теряешь, и поделить на трудоёмкость. Номера без замера в расчёт не идут — врать про них хуже, чем молчать.
- 🩺 **Диагностический срез** — один заход по всем номерам, без таймера и без оценки. После него приложение перестаёт советовать вслепую. Вторую часть решать не просят: вопрос честный и быстрый — взялся бы ты за неё на экзамене.
- 📗 **Справочник** — формулы, ударения, паронимы и разбор каждого номера с поиском по всему сразу. На экзамене по математике и физике справочные материалы дают вместе с работой.
- ♾️ **Задания не кончаются** — приложение собирает их само по 36 номерам четырёх предметов: условие, ответ и разбор считаются из одних и тех же чисел, поэтому ответ верен по построению, а числа каждый раз новые и выучить их нельзя.
- ⬇️ **Загрузка банка с Решу ЕГЭ** — по кнопке приложение забирает задания по каждому номеру с ответами, разборами и чертежами прямо в твой банк, а заодно целые пробные варианты; дальше всё работает офлайн. Задания скачивает твоя копия для тебя — в установщике их нет.
- 🔁 **Интервальное повторение** — ошибся сегодня, вернётся завтра; ответил верно — через три дня, неделю, две с половиной. Уровень считается по дням, а не по попыткам: за один вечер интервал не накрутишь.
- 📌 **«Сегодня» решает за тебя** — один список по порядку: что повторить, какие занятия сделать, какой номер добить. Думать, с чего начать, не нужно.
- ⏱️ **Пробник под таймером** — целый вариант с Решу ЕГЭ закрывает работу полностью, поэтому и время даётся всё, и балл настоящий, а не пересчёт по доле. Вторую часть после таймера оцениваешь сам — по критериям и авторскому решению, как эксперт.
- 📅 **План как календарь и список по дням** — отмечаешь пройденное, кликаешь по занятию для подробностей.
- 🪜 **Три этапа подготовки** — сначала разобраться в каждом разделе, потом довести решение до автоматизма, в конце пробники под настоящим таймером. Видно, на каком этапе ты сейчас и сколько до следующего.
- 📈 **Мотивирующий прогресс** — XP и уровни, серия дней подряд, тепловая карта активности, достижения и **честный приблизительный балл** по каждому предмету (можно выключить).
- 🎉 **Празднования** — конфетти и приятный звук при новом уровне или достижении.
- ⬆️ **Обновляется само** — при запуске Nous проверяет релизы на GitHub и, если вышла новая версия, предлагает поставить её одной кнопкой: скачает установщик, запустит и закроется. План, прогресс и банк остаются на месте — они лежат в папке данных, которую установщик не трогает.
- 🔄 **Синхронизация телефона и компьютера** — одним файлом через своё облако или мессенджер, без сервера. Данные не заменяются, а **складываются**: решал днём на телефоне, вечером на компьютере — останется и то, и другое. Перед слиянием видно, что именно приедет.
- 🔒 **Приватность** — всё локально; файлы и прогресс никуда не уходят.

**Что добавляет ИИ (по желанию)**

- 🧮 **Проверка развёрнутого ответа — можно по фото** — сочинение или задачу с решением не надо переписывать в поле: сфотографируй лист, и ИИ прочитает рукописное решение и разложит баллы по критериям. Критерии можно подтянуть из твоих же материалов (например, из демоверсии ФИПИ).
- 💡 **Работа над ошибками** — на неверном ответе кнопка «Почему я ошибся»: ИИ говорит, где именно сломалось рассуждение. Каждый разбор оставляет метку, и по повторам видно, что дело уже не в невнимательности, а в непонятой теме.
- 📖 **Материал к занятию** — теория по теме и несколько заданий с ответами прямо в карточке занятия; сохраняется внутрь занятия и дальше открывается офлайн, а задания одним нажатием уезжают в тренажёр.
- 🧭 **Разбор недели** — цифры (выполнено, просрочено, слабые номера) считаются офлайн, ИИ только честно комментирует и предлагает, что менять; отсюда же план дополняется по слабым темам.
- 🪄 **Дописать или переделать план** — опиши обычными словами, что добавить.
- 💬 **Чат с ИИ-репетитором** — знает твои предметы и цели; объяснит тему, разберёт задание.
- 👁️ **ИИ со зрением** — приложение само выбирает самую умную из доступных моделей и при равном уме предпочитает ту, что **видит картинки**: без этого не проверить фото решения. На бесплатном ключе ModelScope это Qwen3-VL-235B — она и задачи ЕГЭ решает, и рукописный лист читает.
- 💻 **Без ключей** — Ollama или LM Studio на твоём компьютере: ИИ работает офлайн и без лимитов.
- 🇷🇺 **Работает из России без VPN** — проверено живыми запросами с российского адреса. Доходят напрямую: **ModelScope** (Qwen3-VL-235B со зрением, бесплатно), **Cloud.ru** (GigaChat и Qwen3-VL по обычному ключу — без сертификата Минцифры и без OAuth), **VseGPT** и **ProxyAPI** (российские ретрансляторы к GPT и Claude), Hugging Face, Together, DashScope, SambaNova, Mistral. Блокируют российские адреса: OpenRouter, Groq, Cerebras, Google Gemini, NVIDIA, Novita.
- 🔀 **Лимит кончился — берётся следующий** — введи ключи от нескольких сервисов, и приложение само переключится, когда у текущего кончится дневная квота. Молча: ты этого не заметишь.
- 🔒 **Есть VPN — включи галочку** — «ходить к ИИ через VPN» в настройках. Без неё приложение ходит напрямую и включённый VPN не замечает, а с ней оживают все заблокированные сервисы.

## 📦 Установка (для всех)

1. Открой раздел **[Releases](../../releases)** этого репозитория (⚠️ не зелёную кнопку «Code → Download ZIP» — там исходники, они не нужны).
2. Скачай установщик **`Nous_x.y.z_x64-setup.exe`** и запусти. Мастер спросит, **в какую папку установить**, и создаст **ярлык на рабочем столе**.
3. Запусти Nous с ярлыка — и можно пользоваться: план, расписание, материалы и тренажёр работают сразу.
4. Если захочешь ИИ — в «Настройках» выбери провайдера: бесплатный **[ModelScope](https://modelscope.cn/my/myaccesstoken)** (работает из России напрямую, ~2000 вызовов в день, есть модель со зрением) или локальную модель **Ollama / LM Studio** — ей ключ вообще не нужен.

> Нужен Windows 10/11 (обычно уже есть Edge WebView2). Ключ, если он есть, вводится один раз и хранится локально.
>
> **Без установки:** если не хочешь ставить — в релизе есть портативная версия `Nous-x.y.z-portable.zip`: распаковал, запустил `Nous.exe`, работает откуда угодно (хоть с рабочего стола, хоть с флешки).

> **Ошибка «Could not find the WebView2 Runtime»?** Nous рисует интерфейс движком Edge WebView2 —
> он есть в Windows 10/11 по умолчанию, но пропадает, если систему «чистили» от Edge. Обычно хватает
> [установщика с сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
>
> Если установщик отработал, а ошибка осталась, — в реестре висит запись об уже удалённом рантайме,
> и установщик из-за неё считает, что ставить нечего. Лечится так: запусти PowerShell **от имени
> администратора** и выполни две строки — первая убирает запись, вторая ставит рантайм заново.
>
> ```powershell
> reg delete "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /f
> iwr "https://go.microsoft.com/fwlink/p/?LinkId=2124703" -OutFile "$env:TEMP\wv2.exe"; & "$env:TEMP\wv2.exe" /silent /install
> ```
>
> Проверить, что получилось: папка `C:\Program Files (x86)\Microsoft\EdgeWebView\Application` должна
> появиться на диске. Если её нет — рантайм так и не встал, одной записи в реестре мало.

> **Синее окно «Система Windows защитила ваш компьютер» (SmartScreen)?** Это не вирус — так Windows реагирует на любые новые программы без платного сертификата издателя. Нажми **«Подробнее» → «Выполнить в любом случае»**, и приложение запустится (потом это окно больше не появляется).

## 🛠️ Сборка из исходников

**Требования:** [Node.js](https://nodejs.org) 18+, [Rust](https://rustup.rs); на Windows — WebView2 (обычно уже установлен).

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # сборка установщика .exe
```

Готовый установщик появится в `src-tauri/target/release/bundle/nsis/`.

**Стек:** Tauri 2 · React 19 · TypeScript · Vite · Rust (тонкий прокси к провайдерам ИИ + локальное хранение файлов) · pdf.js · recharts.

**Где что лежит**

| Файл | Что внутри |
|---|---|
| `src/lib/schedule.ts` | раскладка плана по дням: закреплённые занятия, дни недели, выходные, потолок нагрузки |
| `src/lib/offlinePlan.ts` | сборка плана без ИИ по структуре КИМ |
| `src/lib/presets.ts` | готовые стратегии подготовки: с нуля, до порога, на высокий балл, спринт |
| `src/lib/taskgen.ts` | генератор заданий: условие, ответ и разбор из одних и тех же чисел |
| `src/lib/sdamgia.ts` | загрузка банка с Решу ЕГЭ: разбор страниц, формулы из alt, чертежи |
| `src/lib/review.ts` | интервальное повторение по истории попыток, без отдельного хранилища |
| `src/lib/today.ts` | «Сегодня»: один упорядоченный список дел вместо планирования вручную |
| `src/lib/score.ts` | честный балл по решённому, с официальными весами и покрытием |
| `src/data/scoring.ts` | веса заданий и шкалы перевода (сверено со спецификациями ФИПИ) |
| `src/data/demo2027.ts` | задания демоверсии ФИПИ с ответами — эталон для сверки своих данных |
| `src/data/egeTasks.ts` | номера и темы заданий ЕГЭ (структура 2027 года по спецификациям ФИПИ) |
| `src/lib/extract.ts` | извлечение текста из PDF/DOCX/EPUB/TXT/CSV — офлайн, с определением кодировки |
| `src/lib/bank.ts` | банк заданий: разбор своих таблиц, поиск заданий в материале, проверка ответов, статистика |
| `src/lib/aiTutor.ts` | то, что умеет только ИИ: проверка по критериям, материал занятия, разбор недели |
| `src/lib/providers.ts` | провайдеры ИИ, включая локальные Ollama и LM Studio |
| `src-tauri/src/lib.rs` | хранение состояния и файлов материалов, прокси-запросы к моделям |

## 🔒 Приватность

Приложение полностью локальное. План, прогресс, банк заданий и API-ключ хранятся только на твоём ПК (в файле состояния), загруженные материалы — рядом, в папке приложения. Запросы к ИИ идут напрямую к выбранному провайдеру с твоим личным ключом, а с локальной моделью не покидают компьютер вовсе. Своего сервера и телеметрии нет.
